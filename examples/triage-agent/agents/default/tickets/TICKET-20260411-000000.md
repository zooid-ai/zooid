# Increase "Get Started" button tap target size for mobile

**Package:** packages/homepage
**File(s):** packages/homepage/src/components/Hero.astro
**Severity:** medium
**Type:** a11y

## Original report

> the get started button on the homepage is too small, hard to tap on mobile

## What I found

The primary CTA is an `<a>` tag with class `.get-started-button` in `packages/homepage/src/components/Hero.astro` (line 12). Current styles (lines 36–46):

```css
.get-started-button {
  display: inline-block;
  padding: 0.4rem 0.9rem;
  background: var(--accent);
  color: #fff;
  border-radius: 4px;
  text-decoration: none;
  font-size: 0.875rem;
  font-weight: 500;
  transition: background 0.15s ease;
}
```

The `padding: 0.4rem 0.9rem` and `font-size: 0.875rem` are secondary-action sizing; the tap target falls well below the 44×44 px minimum recommended by WCAG 2.5.5 and Apple/Google mobile HIG guidelines.

**No second CTA button exists.** The hero section contains only this one link — there is no adjacent "Learn more" or secondary button that would share the same problem.

## Suggested change

In the `.get-started-button` rule, increase `padding` to at least `0.75rem 1.5rem` and raise `font-size` to `1rem` (or `1.125rem`) so the rendered tap target meets the 44 px minimum on common mobile viewports. Optionally add a `min-height: 44px` / `min-width: 44px` guard. No layout changes to surrounding elements should be needed — the button is `display: inline-block` inside the hero flex container.

## Verification

Open the homepage on a 375 px-wide viewport (iPhone SE / Chrome DevTools mobile preset). The button should be comfortably tappable with a thumb and its bounding box should measure ≥ 44×44 px in DevTools.
